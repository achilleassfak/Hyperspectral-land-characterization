# Characterization of Land Areas Using Hyperspectral Content and Deep Learning Techniques

Diploma thesis - Electrical & Computer Engineering, Technical University of Crete.

A deep learning pipeline for **UAV-based crop health segmentation** from hyperspectral imagery. The project asks a practical question: *how much spectral information does a model actually need to accurately map crop health?* - and finds that a custom U-Net using just **4 bands (RGB + near-infrared)** matches, and slightly exceeds, the accuracy of the full 200-band hyperspectral cube.

That matters in practice: RGB+NIR sensors are far cheaper and lighter than full hyperspectral cameras, so this result suggests high-accuracy crop health mapping is achievable with much more accessible hardware.

## Key result

Each scenario (L0–L8) progressively removes spectral bands, from the full 200-band cube down to a 3-band true-RGB image and a 4-band RGB+NIR image. Two architectures were trained and evaluated on every scenario: a custom **HSI-UNet** (BatchNorm + Dropout, 3-level encoder/decoder) and a **baseline U-Net** (Ronneberger et al., 2015).

| Scenario | Bands | Model | Overall Acc. | mIoU | F1 (macro) |
|---|---|---|---|---|---|
| L0 - Full spectrum | 200 | Original U-Net | 92.14% | 0.804 | 0.885 |
| L0 - Full spectrum | 200 | **HSI-UNet** | 93.79% | 0.839 | 0.909 |
| L7 - True RGB | 3 | Original U-Net | 81.88% | 0.637 | 0.760 |
| L7 - True RGB | 3 | **HSI-UNet** | 84.79% | 0.676 | 0.793 |
| **L8 - RGB + NIR** | **4** | Original U-Net | 91.74% | 0.795 | 0.879 |
| **L8 - RGB + NIR** | **4** | **HSI-UNet** | **94.39%** | **0.852** | **0.917** |

The custom HSI-UNet outperforms the baseline across every scenario, and the 4-band RGB+NIR configuration (L8) achieves the best result of all nine scenarios tested - better than using the full hyperspectral cube. Full results for all 9 scenarios × 2 models are in [`results/Final_Thesis_Comparison_Table_Full.csv`](results/) (generated by the training notebook).

Segmentation classes: `Background`, `Severe stress`, `Moderate stress`, `Healthy`.

## Pipeline

1. **Ground truth generation** (`notebooks/01_ground_truth_generation.ipynb`)
   - Cleans and filters raw UAV hyperspectral patches (removes empty/low-signal/corrupt patches).
   - Derives per-pixel health labels from a **consensus vote across four vegetation indices** (NDVI, GNDVI, SAVI, EVI), each thresholded into stress classes and weighted, with a median filter for spatial consistency.
   - Applies **soil suppression**: pixels below an NDVI threshold are forced to background, regardless of the vegetation-index vote, to prevent bare soil from being misclassified as crop.
   - Produces a class-balanced train/validation/test split via entropy-based stratification.
   - Generates a **band-exclusion dataset series** (L0–L8), progressively restricting the spectral range from the full 200-band cube down to 3-band RGB and 4-band RGB+NIR, to test how much spectral information the model actually needs.

2. **Training & evaluation** (`notebooks/02_train_evaluate.ipynb`)
   - Trains both `HSI_UNet` (custom) and `Original_UNet` (baseline) on every band-exclusion scenario.
   - Data augmentation: horizontal/vertical flips, rotations, **CutMix** (patch swapping between samples), spectral Gaussian noise, and random band dropout.
   - Class-weighted cross-entropy loss to handle label imbalance; `AdamW` optimizer with plateau-based learning rate scheduling.
   - Evaluation via overall accuracy, mean IoU, and per-class F1 score on a held-out test set.
   - **Full-orthomosaic inference**: sliding-window prediction (patch size 96, stride 48, softmax-averaged over overlaps) to segment entire drone-captured field mosaics, including multi-temporal (multi-season) comparison.

## Repository structure

```
├── src/
│   ├── models.py                          # HSI_UNet and Original_UNet architectures
│   └── dataset.py                         # SatelliteDataset + DataLoader construction
├── notebooks/
│   ├── 01_ground_truth_generation.ipynb   # Dataset cleaning, VI-based labeling, band-exclusion datasets
│   └── 02_train_evaluate.ipynb            # Training loop, evaluation, full-image inference (imports from src/)
├── docs/
│   └── thesis.pdf                         # Full thesis document
├── results/
│   └── Final_Thesis_Comparison_Table_Full.csv   # Output of the evaluation notebook
├── requirements.txt
└── README.md
```

The model and dataset code lives in `src/` as plain Python modules rather than being defined inline in the notebook, so it can be reused or imported elsewhere (e.g. for inference scripts) without re-running the whole notebook.

## Setup

```bash
git clone https://github.com/<your-username>/<repo-name>.git
cd <repo-name>
pip install -r requirements.txt
jupyter notebook
```

Run `01_ground_truth_generation.ipynb` first to build the labeled, band-exclusion dataset series, then `02_train_evaluate.ipynb` to train and evaluate the models. Dataset paths at the top of each notebook are placeholders - point them at your own copy of the UAV hyperspectral dataset (raw data is not included in this repo due to size).
